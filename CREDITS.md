# Credits

This repository redistributes **personal subsets** of public wallpaper collections. I did not create the artwork.

## Primary sources

| Pack in this repo | Original GitHub repo | Maintainer |
|-------------------|----------------------|------------|
| `w/` | https://github.com/thor-op/w | [thor-op](https://github.com/thor-op) — “A Curated Wallpaper Collection For Wavo Walls Website” (MIT) |
| `wall-archive/` | https://github.com/vimlinuz/wall-archive | [vimlinuz](https://github.com/vimlinuz) — curated multi-style wallpaper archive |

Local folders are **incomplete mirrors** (favourites / what fits on this machine), not full upstream trees.

## Related

- [dharmx/walls](https://github.com/dharmx/walls) — large categorized wallpaper set common in Linux rices  
- [omacom/omarchy](https://github.com/omacom/omarchy) — Omarchy OS (theme backgrounds are separate from this pack)  
- [mysh264/omarchy-dotfiles](https://github.com/mysh264/omarchy-dotfiles) — desktop configs that consume `~/.Wallpapers`

## Artists

Many files originate from anonymous or third-party illustrators (anime stills, photography, AI-assisted art, etc.) collected by the upstream maintainers. Exact per-file artist metadata is often unavailable. If you are a rights holder and want attribution added or a file removed, please open an issue on this repo or contact the upstream maintainer.
